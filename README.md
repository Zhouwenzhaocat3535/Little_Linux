### 🔴 Known risks (read before running)
- All applications run in **Ring0** → no memory protection → any bug = whole system crash.
- No runtime file execution prevention is perfect – vulnerabilities exist.
- Currently **untested on real hardware**. Run only in **QEMU / VM**.
